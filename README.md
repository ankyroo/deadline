# DEADLINE

### Stop forgetting. Start doing.

**DEADLINE** is a task and time management application built to help you keep your life under control.

We all have things to do. University assignments, work, personal projects, random responsibilities that somehow appear out of nowhere. And somehow, we are expected to remember all of them.

DEADLINE is here to fix that.

The idea is simple: put everything in one place, understand what is important, keep track of your time, and actually get things done.

No unnecessary complexity. No productivity guru bullshit. Just a tool that helps you stay organized.

---

## Why?

Most task managers are basically digital notebooks. You write something down, set a date, and hope you remember to check it.

But a deadline is more than just a date.

Some tasks can wait. Some need attention today. And some are already dangerously close to becoming a problem.

DEADLINE is built around this difference.

It should help you answer three questions:

- What do I need to do?
- What should I do first?
- How much time do I have left?

That's it. That's the whole idea.

## What can DEADLINE do?

*The following is the planned feature set. Not everything is implemented yet.*

### Task Management

All your tasks in one place.

- Create, edit and delete tasks.
- Set deadlines.
- Assign priorities.
- Track completion status.
- Keep everything organized.

### Priority System

Not every task deserves the same amount of attention.

DEADLINE uses a simple color system:

- 🟢 Green — Low priority. Nothing is on fire.
- 🟡 Yellow — Medium priority. Probably worth doing soon.
- 🔴 Red — High priority. Stop procrastinating.

The goal is to make important things impossible to overlook.

### Calendar

A calendar that actually helps you plan your life.

- Daily and monthly views.
- Upcoming deadlines.
- Visual task distribution.
- Quick access to scheduled tasks.

### Deadline Tracking

Time doesn't stop just because you forgot about an assignment.

- Countdown to deadlines.
- Overdue task tracking.
- Upcoming deadline overview.
- Task urgency indicators.

### Reminders & Notifications

Because remembering everything manually is a terrible productivity system.

- Deadline reminders.
- Notifications about important tasks.
- Customizable reminders.
- Alerts for approaching deadlines.

### Time Tracking

It's easy to think you've spent thirty minutes on something when it's actually been three hours.

Planned functionality:

- Built-in task timers.
- Time tracking.
- Planned vs. actual time.
- Daily time overview.

### Notes

Sometimes a task needs more than just a title.

- Personal notes.
- Pinned information.
- Additional task details.
- Quick access to important information.

### Statistics

A little self-awareness never hurt anyone.

- Completed tasks.
- Overdue tasks.
- Productivity statistics.
- Time spent working.
- Personal progress.

The point isn't to turn your life into a competition with yourself. It's to understand where your time actually goes.

## Tech Stack

Currently built with:

- **Next.js** — Application framework.
- **React** — UI.
- **TypeScript** — Type safety.
- **Supabase** — Backend and database.
- **Vitest** — Testing.

The project is built with maintainability and scalability in mind. I want DEADLINE to be something that can grow without turning its codebase into a complete disaster.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/ankyroo/deadline.git
cd deadline
```

Install dependencies:

```bash
npm install
```

Configure your environment variables for Supabase.

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000`.
